# 枣庄市妇幼保健院“童心筑梦新时代 献礼百年心向党”儿童艺术节第三场专题声乐会举办

> 更新时间：2026-09-16 (UTC+8)

为持续开展庆祝建党100周年活动，激发少年儿童热爱祖国、热爱中国共产党的热情，7月17日下午，枣庄市妇幼保健院“童心筑梦新时代 献礼百年心向党”儿童艺术节第三场专题声乐会如期而至。本场声乐会的节目由云生艺术培训学校的师生精心编排，为现场观众呈现歌唱表演、舞蹈展示等多样化的视觉盛宴。院工会主席李玉芹出席活动并致辞。

院工会主席李玉芹代表医院领导班子及全体职工向一直奋战在守护儿童健康一线的社会各界表示崇高的敬意和衷心的感谢，她指出，孩子是祖国的花朵，更是国家的未来，守护孩子身体健康是全社会共同的心愿。她表示，自6月1日儿童节以来，为使全市少年儿童度过一个快乐、充实、有意义的节日，枣庄市妇幼保健院面向全社会举办2021年儿童艺术节庆祝活动，旨在以建党百年的红色主题为引擎，进一步掀起庆祝党的生日和对少年儿童进行思想政治教育的新热潮，同时为喜爱艺术的少年儿童搭建一个展示艺术才华的发展空间和艺术提升平台，让每个孩子在活动及自我展现中感受爱国主义教育、培树自信心、增强爱国意识，使他们充分感受到节日的快乐和社会的关爱。她希望，医院能够与社会、家长们一起并肩携手，为少年儿童身体健康保驾护航。活动现场，参加表演的小朋友们被授予“枣妇幼小志愿者”称号，院工会主席李玉芹为小志愿者代表佩戴绶带以亮明“小志愿者”身份。

活动在《勇往直前》歌声中正式开启，紧接着歌伴舞《傈僳火旺旺》、歌曲《军中娃》、《嘿，小小火箭兵》以及歌舞《黄河源头》等40余个精彩节目轮番上演，孩子们热情洋溢的表演感染着现场观众，博得阵阵热烈掌声。

孩子们通过精彩的表演获得了好评，同时也收获了各自的荣誉和掌声。

本次音乐节的成功举办，深入挖掘了少年儿童对祖国的热爱之情，充分展示了小朋友们积极向上、奋发有为的新时代少年儿童风采，同时，孩子们也用歌声、以舞蹈的方式庆祝建党100周年，致敬时代，表达了对中国共产党的浓浓热爱之情，萌发出他们从小作为一名中国人的由衷自豪感。
