# 促排卵33个后要休息多久？休息一会儿移植也不迟

## 促排促排卵33个要休息多久才能移植

正常来讲促排卵后休息一至两天或者一周后，那么身体的情况就可以进行移植了，不过移植胚胎的话也需要等胚胎培育出之后，但对于取出33个母细胞的情况，则需要休息调养两至三个月后，才能正常的移植胚胎，因为促排卵数量多，对卵巢的损伤比较大，因此就需要多休息以及调养，待身体恢复到一个良好状态时，才可以移植。

**促排卵后的休息注意事项：**

- 1. 促排卵后不用特别卧床休息，如果没事的就多躺着，上班就看你的工作是怎么样的；
- 2. 促排卵后多喝水，多排尿，防止腹水，没有腹水的话不需要卧床，只要身体没有不适可以随便干什么；
- 3. 取完卵看情况，如果你取的卵少就可以行动自由。如果你取的卵多，就要多喝蛋白粉，动作慢点，平时动作要小；
- 4. 取完卵如果没有什么不适的话不需要卧床，只是不要剧烈运动就好。
其实对于促排卵后的休息，无论促排卵的多少，那么都需要一至两天，只是移植的话根据促排卵数量上面来讲，时间就不同了，像促排卵33个的情况，在休息后，那么生活方面正常就行，而调养的话，如吃高蛋白以及维生素的食物，而去要规律作息时间，并且禁止性生活，这样才能利于恢复，以及比较好的状态移植。

## 促排卵33个没有腹水能否移植鲜胚

一般来讲，促排卵后没有腹水，那么是可以移植鲜胚的，但对于促排卵33个，即便没有腹水，那么也不能移植鲜胚，因为不腹水，那么卵巢受到的刺激是必然的，因此需要一定的时间去恢复卵巢，而卵巢的恢复时间，通常在1-3个月左右，因此移植鲜胚就不可能了，所以就会将鲜胚冷冻起来后，待卵巢恢复后才能移植胚胎。

**哪些情况不能移植鲜胚：**

- 1. 在促排卵过程中B超提示卵巢较大，卵泡较多，获卵数目较多，为了防止出现卵巢过度刺激综合征，以及进一步的严重并发症，会建议将胚胎冷冻，待卵巢恢复正常后才将胚胎移植入体内；
- 2. 移植日雌激素量超过2500pg/ML，或者移植时的雌激素量较促排卵进的雌激素量更高，有发生腹水的风险的也不能移鲜胚；
- 3. 促排卵的过程中出现输卵管的积液问题，为了提高成功几率，需要先处理盆腔，等都处理好后再移植，这时候只能移植冷冻胚胎；
- 4. 促排过程中发现子宫内膜过厚，或者内膜很薄，甚至有不均匀的回声，或有内膜病变问题的女性，促排卵后要等身体调理好后再移植冷冻胚胎；
- 5. 促排卵后女性患有感冒发热、感染性腹泻等疾病时也可能要推迟胚胎移植时间，只能移植冷冻胚胎。

对于移植鲜胚的情况以上这几点可以详细的了解，其实促排卵数量正常，并且没腹水的话，对于卵巢的刺激，其实两天就能恢复，后面移植鲜胚就可以，但对于促排卵数量多之后，就会有很多影响，因此就只能移植冻胚了。
